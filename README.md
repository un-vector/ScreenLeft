# Screen Left
Shows "• h:mm" (daily limit minus today's screen time) in the status bar, right after the clock.

## Build (Android Studio)
1. File > Open > select the ScreenLeft folder, wait for Gradle sync.
2. Build > Build Bundle(s)/APK(s) > Build APK(s).
3. APK: app/build/outputs/apk/debug/app-debug.apk. Copy to phone and install.

## First run
Open "Screen Left", then buttons 1 > 4 in order. Set your limit and tap Save.
Tap "Hide from app drawer" when you're happy. Reopen settings by tapping its notification.
